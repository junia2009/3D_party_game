# タイトル画面

ゲームの「世界の入口」。最初に目に入るので、いちばん作り込む。

## 流れ

1. **読み込み**: どんぐりが転がって待つ。3D とキャラを読み込む。
2. **タイトル**: 空に浮かぶ小島の3Dシーン。木の看板のロゴが枝からつるされて揺れる。
   「タップしてはじめる」。短いジングル。
3. **メインメニュー**: 3Dシーンはそのまま、木の板のボタンが並ぶ。
   - すごろく(大会)… ステージ選択(地図の本)→ 入口(ターン数・キャラ)→ 盤。くわしくは [TAIKAI.md](TAIKAI.md)
   - ミニゲーム(競技)
   - オンライン … じゅんびちゅう
   - キャラ図鑑・ごほうび / あそびかた・せってい(この 4つは 半分の 板で 2つずつ ならべる)
4. **競技えらび**: ミニゲームの一覧(いまは「第1競技 だるまさんがころんだ」だけ)。
5. **競技の入口**: ルールとキャラえらび。島を上の段に出したまま、下に木わくの紙で出す。
   キャラを選ぶと、島の上のそのキャラがよろこぶ。ボタンの顔は実物のモデルを撮った絵(`src/title/portraits.js`)。
6. **会場へ**: 「スタート!」でカメラが島の大木へ飛びこみ、葉っぱの幕(`src/title/leaves.js`)が画面をうめる。
   うまっているあいだに会場を入れかえ、葉っぱが吹きとぶと、会場の空から自分のうしろへ降りていく。
   いちじていし・結果から「キャラをかえる」「メニューへもどる」と、同じ幕で島へもどる(葉の中から引いて島が見える)。

7. **キャラ図鑑**: 島の前に木の表紙の本が出てきて、表紙がひらく(`src/title/zukan.js`)。
   横長は左右に、縦長は上下にひらく。片方のページにキャラ(実物のモデル。ドラッグで回り、さわるとポーズ)、
   もう片方にプロフィール(とくい・せいかく・見分け方・のうりょく)。ページのすみ・はらう・下のしおり(顔)でめくる。

8. **あそびかた**: 森の 紙芝居(`src/title/howto.js`)。木の 舞台の とびらが ひらいて、ホーホー先生が 読む。
   4章(このゲーム・すごろく・ミニゲーム・オンライン)、17まい。上の しおりで 章へ とぶ。
   「つぎへ」で いまの 札を 横へ ぬく(紙芝居の ぬきかた)。札を 横に はらっても めくれる。
   - 絵は 手描きふうの SVG(色の かさね + 鉛筆の 線)。キャラは 実物の モデルを 撮った 顔を シールの ように はる。
     動くのは いまの 札だけ。重い SVG フィルターは つかわない(スマホで かくつく)。
   - はじめて すごろくを えらんだ とき、先生が「あそびかたを 見ておくかい?」と きく(`localStorage['dongurinpic.howto']`)。
     見たら、さいごの「あそぼう!」で ステージえらびへ。
   - ルールの 数字(どんぐり 20こ・青 +3 など)を かえたら、紙芝居の ことばも なおす。

9. **ごほうび**: どんぐりガチャ・きせかえ・称号・スタンプ帳(`src/title/reward.js`)。上の 舞台は 小さな canvas の 3D
   (ガチャの ときは どんぐりの 形の ガチャの 機械、ほかは 自分の キャラが 台の 上で きせかえを 見せる)。
   - しくみは `src/collect/`: 一覧(`catalog.js`)、記録(`progress.js`。どんぐり貯金・ガチャ・称号・スタンプ。THREE にも DOM にも 触らない)、
     3D(`look3d.js`。ぼうしと スカーフの 柄)、結果の しらせ(`report.js`)。
   - 競技は おわると `reportResult` で 結果を window へ しらせる。タイトルが 遊びかたを 見て どんぐりを 足す
     (大会の 中の 競技は 数えない。大会は おわりに `reportTaikai`)。足した 分・スタンプ・称号は 上から すべりこむ おしらせ。
   - きせかえは キャラを 作る ところ(`createModel`)で つく。だれが 何を つけるかは `setLooks`(自分は いつも 自分の キャラ。オンラインは 顔ぶれの look)。
   - オンラインでは hello で look(ぼうし・スカーフ・称号)を おくる。サーバーは 知らない key を すてる(`cleanLook`)。名簿の 名前の 下に 称号

**全部が1つのページ(`index.html`)で動く。** ページを読みこみ直さないので、まっ白にならない。
描画の器(renderer)と毎フレームの輪はタイトル(`src/title/title.js`)が持ち、
競技は `createDaruma()` で組み立てて `frame()` を呼んでもらう。会場は入口をひらいたときに裏で組み立てはじめる。

組み立てた競技は ひとつだけ 手もとに おく(大会の あいだは 大会の 盤も)。ほかの 競技を ひらくと、前の 競技は 片づける。
大会の 競技は 遊びおわったら すぐ 片づけ、大会から もどったら 盤も 片づける(`src/title/release.js`)。
- 組み立てる あいだに 付いた 入力の 受け口(window・ボタン)と、window に 生えた 確認用の 口(`dxxx`)を 記録しておき、片づける ときに はずす。
  受け口が のこると、そこから 会場ぜんぶが つながったままで メモリが 返らない。
- 会場の 形・材質・テクスチャは dispose して GPU の メモリも 返す(同じ ものを また 使えば three が のせなおす)。
- のこしつづけると、大会で 競技を 次々 遊ぶうちに メモリが ふくらんで(15競技で 約 580MB)、スマホでは ページごと 読み込みなおされて タイトルに もどってしまう。
`#menu` でメニューから、`#daruma` でだるまの入口からひらける(前の `daruma.html` はここへ送るだけ)。

ブラウザの戻るボタンは無いものとして作る。どの画面にも、ひとつ前へ戻るボタンを置く。

## 3Dシーン: 空に浮かぶ小島

- 雲の上に、まるい小島が浮かんでいる。上は草地、下は地層の見える岩で、根っこが垂れ下がる。
  ふちから小さな滝が流れ落ちる。
- 島のまん中に、どんぐりの大木。ホーホー先生が枝にとまって見守る。
- 6人が島の上で遊んでいる(手をふる・追いかけっこ・とびはねる…)。
- カメラはゆっくり島のまわりを回る。

## ロゴ: 木の看板

- 丸太を切った板に「ドングリンピック」を彫りこみ、葉っぱとどんぐりで飾る。
- 上の枝(画面の外)から縄でつるされて、ゆらゆら揺れる。

## メニューの見た目

- ロゴと同じ木の板。押すとへこむ。じゅんびちゅうの項目は色を落とし、札をかける。
