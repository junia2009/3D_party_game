# お祭りの 大なわとび

お祭りの夜の広場で、森の なかま2人(リスと ハリネズミ)が 大なわを 回す。5人は 横に ならんで いっせいに とぶ。
なわに ひっかかったら 脱落。最後の1人が 勝ち(勝ちぬき・20〜40 秒)。

## ルール(`src/games/nawa/rules.js`)

- なわの 角度 theta: 0 が 足もと、π が 頭の上。2π の倍数を こえる しゅんかんが「通る」。
  「よーい」3 秒は 頭の上で 止まっていて、はじめの 1回は 半周で 足もとに 来る。
- 通る しゅんかんに 足の 高さが 0.1m(大なみは 0.38m)より 上なら セーフ。下なら 脱落。
  同じ回に 何人か ひっかかったら、低かった子ほど 順位が 下。
  のこっている子が みんな いっしょに ひっかかったら、だれも 脱落しない(3回 つづいたら ふつうに 脱落、いちばん 高かった子だけ のこる)。
- とぶ: おした しゅんかんに ジャンプ(4.2m/秒・重力 32)。0.12 秒 おしつづけると、空中で もう1回 ぐーんと(4.6m/秒)= 大ジャンプ。
  スマホの ふつうの タップ(0.1 秒くらい)では 大ジャンプに ならない。着地のあと 0.1 秒は とべない。
  - ふつうの ジャンプ: 空に 0.25 秒・セーフの まど 約 0.18 秒(おしてから 0.03〜0.22 秒)。
  - 大ジャンプ: 空に 0.45 秒。大なみの まど 約 0.15 秒。空に 長く いるので、速い なわでは つぎに まにあわないことも。
- だんだん速く: 1回 1.4 秒から、回すたびに ×0.972(さいはや 0.56 秒)。
  8回目からは 10% で 1回だけ 急に ゆっくり(×1.7)= ふいうち。
- 大なみ: 4回目から 18% で、なわが 高い ところを 通る。なわが 頭の上を こえた ときに わかる(「大なみ!」)。
  つづけては 来ない。大なみの つぎの 1回は 少し ゆっくり(×1.12)。
- じゃまのカエル: 7〜12 秒ごとに カエルが 列の すきまに 入って、4回 いる。くずれた リズムで ぴょこぴょこ とぶ(まどわされる)。
- 順位: のこった子、そのあとは 脱落が おそかった順。

## CPU(`src/games/nawa/cpu.js`)

- なわが 頭の上を こえたら、つぎに 足もとを 通る 時刻から とぶ 時刻を 決める(セーフの まどの まん中を ねらう)。
  ずれ方は 性格しだいで、なわが 速いほど・となりに カエルが いると 大きくなる。
- 大なみに 気づけば 長おし、気づかないと ふつうの ジャンプで ひっかかる。
- ふいうちの ゆっくりに 気づかないと、いつもの 速さの つもりで 早く とんでしまう。
- 性格: しんちょう(大なみ・ゆっくりに よく 気づく)/ ふつう / つよき(ずれは 小さいが、よく 見ていない)。

## 画面(`src/games/nawa/game.js`, `stage.js`)

- 会場: 森に かこまれた 夜の 広場。5人は となりと 重ならない 間を あけて、みんな 同じ 横向き(右向き)で 1列に ならぶ。回す2人は 内がわを 向く。勝った子は こちらを 向いて よろこぶ。奥に 紅白の 幕の やぐら(上で ホーホー先生が 大太鼓)。
  やぐらの てっぺんから まわりの 柱へ ちょうちんの ひも。左右の 奥に 屋台(わたあめ・やきそば・きんぎょ)。
- なわ: 回す2人は 間を ひろく とって、黄色い なわを 自然な 弧で 回す。いちばん 下では まん中が 地面を たたく。
  まん中ほど 手もとより 少し おくれて ついてくる(しなる)。大なみの 1回は ふれはばが 小さく(高い ところを 通る)。
  通るたびに 先生の 太鼓が ドン。
- ひっかかった子は その場で めをまわして、列の うしろへ 下がって 見る。
- カエル: 小さな みどりの カエルが 横から ぴょんぴょん 来て、すきまで ばらばらに とぶ。ゲコッ。
- カメラ: 斜め前(とぶ子が 向いている 右がわの 手前)から、列と 回す2人を いっしょに 見せる。その 向きの 森の 木は よける。
- HUD: 上に のこっている子(脱落は 灰色)と とんだ回数。下に 長おしの 輪(大ジャンプまで。満ちると 金色)。「大なみ!」は 大きく。
