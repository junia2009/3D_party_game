# お正月の だるまおとし

雪の 夜の 森の お寺。たたみの 大広間で、みんなで 1つの だるまを じゅんばんに こづちで たたいて、いちばん 下の だんを ぬく。
くずした 子は アウト。のこりの 子で つみなおして つづけ、さいごの 1人が 勝ち。

## ルール(`src/games/otoshi/rules.js`)

- だるま: あたまの 下に だんが 5つ。はじめの じゅんばんは くじ(席の 順に まわる。アウトの 子は とばす)。
- じぶんの ばん(5 秒): おして いる あいだ ためる。つよさは 0→1→0 と 1.5 秒で いったり きたり。はなすと たたく。
  時間ぎれは ためて いる つよさで(ためて いなければ 0.15 で)たたく。
- だんの しゅるいと ちょうどいい つよさ:
  - ふつう 0.38〜0.68 / かたい(石)0.68〜0.93 / すべる(つるつる)0.12〜0.38。まざる わりあいは かたい・すべる 2わりずつ。
  - いちばん 下の だんが ずれて いると、ずれた ぶん よわくて いい。
  - ぜんぶ ぬいて つみなおす たびに、はばが 22% ずつ せまく なる(いちばん せまくて 12%)。
- たたいた けっか:
  - よわすぎ: だんが ずれる だけ。ぐらぐら +0.1
  - ちょうどいい: だんが ぬけて だるまが 1だん さがる。ぐらぐら +0.12 + 0.55 ×(まんなかからの ずれ)²。まんなか 35% いないは「ぴったり」
  - つよすぎ: ぬけるけど ぐらぐら +0.75 + こえた ぶん × 3
  - ぐらぐら して いる ときに たたくと、たす ぐらぐらが (1 + いまの ぐらぐら × 1.5) ばい。
- ぐらぐら: 1秒に 0.14 おさまる。1 を こえたら くずれて、たたいた 子が アウト。
- だんを ぜんぶ ぬいたら「おみごと!」。つみなおして つぎの 子から(すこし むずかしく)。
- 順位: のこった 子 → アウトが おそかった 順 → ぬいた 数 → 席。

## CPU(`src/games/otoshi/cpu.js`)

- 人と おなじく「おす・はなす」だけ。見て いるのは ぐらぐらと、いちばん 下の だんの しゅるい(と ずれ)。
- ぐらぐらが ある くらい(patience)に おさまるまで まつ。時間が なく なったら(rush)またずに ためる。
- ちょうどいい はばの まんなかを ねらって、のぼりの とちゅうで はなす。手が ずれる(aim)。
- 性格: しんちょう(よく まつ)/ ふつう / つよき(あまり またない)。

## 画面(`src/games/otoshi/game.js`, `stage.js`)

- 会場: たたみの 大広間。おくに しょうじ(雪の かげが うつる)、かどまつ、もちつきの うすと きね、かがみもち、ちょうちん。
- だるま: 色の だん(かたい だんは 石、すべる だんは こおりの ような つるつる)と 赤い だるまの あたま。ぐらぐらで かたむく。
- たたく 子は だるまの 左へ 出て こづちを ひく(ためるほど うしろへ)。ほかの 子は うしろで 見る。
- ぬけた だんは 右へ とんで ころがる。くずれると ぜんぶ ばらばらに とぶ。つみなおしは 上から ふって くる。
- HUD: だれの ばんか、つよさの ゲージ(みどり = ちょうどいい、金の 線 = まんなか)と だんの しゅるい、のこり時間。
  ぐらぐらが 大きいと 画面の ふちが 赤く 光る。
- 操作: じぶんの ばんに 画面を おして ためる、はなして たたく。パソコンは スペース。
