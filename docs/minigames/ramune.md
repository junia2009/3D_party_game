# 夏祭りの ラムネ しゅわしゅわ

夏祭りの 夜店で、ラムネの びんを ふって あわを ため、「ポン!」で ふたを とばす。スマホを ふる 体感型の 競技。
ためた あわが 多いほど 高く とぶ。3回せんの 合計の 高さで 勝負。

## ルール(`src/games/ramune/rules.js`)

- 1回: 「びんを もって!」1.6 秒 → ふる 8.5 秒 → ふたが とぶ ところを 見る 3.2 秒。3回くりかえす。
- ふる: ふる 強さ(0〜1)× 34 が 1秒ごとに「いきおい」に たまり、いきおいは 1秒に 4ばいの はやさで あわに かわる。
  ふるのを やめても のこりの いきおいの ぶん あわは すこし ふえる。
- こおりが とける: ふって いない(強さ 0.15 未満)あいだ、あわは 1秒に 3.5 へる。
- げんかい: 回ごとに 70〜100(その回は みんな おなじ)。こえると ふきこぼれて その回は 0。
- がたがた: げんかいの 62〜82%(回ごとに ちがう・みんな おなじ)を こえると びんが がたがた。げんかいに 近いほど はげしい。
- ポン: とぶ 高さ = あわ × 0.32 m。時間ぎれで ポンして いなければ 自動で ポン。
- 順位: 合計の 高さ → いちばん 高かった 1回 → 席。

## CPU(`src/games/ramune/cpu.js`)

- 人と おなじく「ふる 強さ」と「ポン」だけ。見て いるのは びんの がたがた(強さ)だけ。
- がたがたが ある 強さ(brave)に なったら、すこし おくれて ふるのを やめ、すこし まって ポン。
- 性格: しんちょう(すぐ やめる)/ ふつう / つよき(がたがたを がまんする)。

## 画面(`src/games/ramune/game.js`, `stage.js`)

- 会場: 夏祭りの 夜店。赤白の ひさしの ラムネ屋台(のれん・水玉の 布・氷水の たらい)、うしろに 金魚すくい・わたあめ・やきそば・かきごおり。
  ちょうちんの ひも、屋台の あかり、夜空の 星。屋台の よこに 高い 竹ざお(5 m ごとに 目もり)。
- 5人が 屋台の 前に ならんで(自分は まん中)ラムネを ふる。ふる 強さで びんが 上下に ゆれ、中の あわが ふえる。がたがたは こまかく ふるえる。
- ポン: ふたが 自分の 色で ひかりながら 夜空へ。カメラが 竹ざおに そって 上へ ついていき、てっぺんで 花火と 高さ。
- ふきこぼれ: あわが ふきだして「ふきこぼれた!」。
- 操作: はじめに「ふって あそぶ / タップで あそぶ」(iPhone は ここで センサーの 許可)。ふれない ときは 画面の 連打。
  パソコンは スペースで ふる・エンターで ポン。
- HUD: 上に みんなの 合計(順位で ならぶ)・何回目か・のこり時間、左に 自分の あわの メーター(げんかいは 見せない)、右下に「ポン!」。
  がたがたが はげしく なると 画面の ふちが 赤く 光る。
