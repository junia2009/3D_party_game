# 森の 倒れ木の どんぐりボウリング

森の 大きな 倒れ木を たてに わって ほった レーンが 5本。5人が いっせいに どんぐりを ころがして、
まつぼっくりの ピンを たおす。3フレームで いちばん 点の 多い 子の 勝ち。

## ルール(`src/games/bowl/rules.js`)

- 5人 同時に 投げる(まち時間なし)。レーンは 5本とも おなじ ならび(金の ピンと じゃまものの 場所も おなじ)。
- 3フレーム。1フレームに 2回まで。1回目で 10本 たおしたら ストライク(2回目は お休み)。2回目の まえに たおれた ピンは かたづける。
- 投げる: 向き(±0.07 ラジアン)・はやさ(3.2〜8.5)・ひねり(-1〜1)。ひねると ころがる うちに まがる(おそいほど よく まがる)。
- レーン: はば 1.06。まんなかが そとへ 出ると みぞ(先頭の ピンより 手前だけ。あとは まっすぐ おくへ)。
- ピン: 10本の 三角。ぶつかって はやさ 0.55 より 強く おされると たおれる。たおれた ピンは すべって ほかの ピンを たおす。
- 金の ピン: フレームごとに 1本。たおすと +3。
- じゃまもの: フレームごとに 2つ(小石 か 木の こぶ)。あたると よこへ それる(よこの はやさは 0.45 まで。すすむ 力は のこる)。
- 点: たおした 本数 + 金の ピン 3 + ストライク 5 + スペア 3。
- 投げない まま 7 秒 たつと、そっと まっすぐ 投げる。
- 順位: 点 → ストライクの 数 → スペアの 数 → くじ(はじめに きめる)。

## CPU(`src/games/bowl/cpu.js`)

- 人と おなじく 向き・はやさ・ひねりを 1回 出すだけ。考える 時間(think)の あと 投げる。
- 投げる まえに 13の 向き × つかう ひねり を ルールと おなじ 計算で ころがして、点を くらべる。
  となりの 向きも ふくめた へいきんで えらぶ(ずれても たおれる 投げかた)。1回目は 5本とも おなじ なので、ためした けっかを みんなで つかう。
- えらんだ 投げかたから ずれる(aim・power・spinErr)。
- 性格: しんちょう(まっすぐ、ゆっくり、ずれが 小さい)/ ふつう / つよき(ひねり 大きめ、はやい、金の ピンを ねらう、ずれが 大きい)。

## 画面(`src/games/bowl/game.js`, `stage.js`)

- 会場: 木もれびの 森。倒れ木の 平らな 面に 木の 板の レーンと みぞ。手前は 年輪の 切り口、おくは こけの かべと 根っこ。
- ピンは まつぼっくり(金の ピンは 金色で ひかる)。玉は 大きな どんぐり。
- キャラは 自分の レーンの 手前に 立つ。投げると 走り、ストライクや スペアで よろこぶ。
- カメラ: 自分の レーンの うしろ。投げたら どんぐりを おいかけて、ピンの 手前で とまる。けっかは ピンを 見る。
- 操作: 画面を 上へ シュッと はじく。さいごの 0.12 秒の うごきで いきおいと 向き、はじめと さいごの 向きの ちがいで ひねり。
  はじいて いる あいだ、レーンに ねらいの 線が 出る。
