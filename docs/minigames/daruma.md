# だるまさんがころんだ

見張り番がうしろを向いているあいだに進み、振り向いたら止まる。いちばん早くゴールに触れた人の勝ち。

## 場面: どんぐりの森の広場

- 森の中にぽっかり開けた広場を、土の小道が抜けていく。コースは 20m、5レーン。
- ゴールには樹齢何百年の**どんぐりの大木**。ホーホー先生はその低い枝にとまって見張る。
- 先生は体をうしろ(森の奥)に向けたまま、**首だけぐるっと回して振り向く**。
- 広がる風景にする。近景(コースまわりの木・切り株・キノコ・シダ・落ち葉)/
  中景(森の木立)/ 遠景(もやのかかった山並み)を重ねて奥行きを出す。木漏れ日の光の筋。
- 風景は動く: 木の葉が風に揺れる、葉っぱが舞う、鳥が飛ぶ、雲が流れる(ルールには関係しない)。

### 時間帯(遊ぶたびに変わる)

| 時間帯 | 光 | その時間だけのもの |
| --- | --- | --- |
| 朝 | 低い白っぽい光、うすい霧 | 朝もや、小鳥 |
| 昼 | 真上からの明るい光、くっきりした影 | 木漏れ日の光の筋 |
| 夕方 | 横からのオレンジの光、長い影 | 赤い空、カラス |
| 夜 | 青い月明かり | ホタル、先生の目が光る |

時間帯はゲームのシードで決まる(オンラインでも全員同じ)。

## しかけ

レーンごとに配置がちがう。ただし**どのレーンにも同じ数ずつ**置き、スタート直後(2m)と
ゴール直前(1m)には置かない。毎ゲーム、シードから配置を作る。

| しかけ | 数(1レーン) | 何が起きるか | ねらい |
| --- | --- | --- | --- |
| ぬかるみ | 1か所(長さ 1.5m) | 中で手を離すと、ふだん(0.15秒)より長く **0.6秒** 滑る。数え終わった瞬間に離しても見つかる(振り向き+猶予は 0.5秒) | 早めに止まる判断を迫る |
| 落ち葉の山 | 1か所(長さ 0.8m) | 数えている間に走って踏むと **ガサガサ** 鳴り、先生の耳がぴくっと動いて、**残りの数えが速くなる**(残り時間が 6割に)。全員が巻きこまれる。鳴った山は散ってしまい、もう鳴らない | 「踏まずに待つか、踏んで進むか」。踏むと他の人にも迷惑 |
| 拾うどんぐり | 2個 | その上で**止まる**と拾える。拾った数は結果に出て、すごろくでボーナスになる | 止まる位置にこだわる理由を作る |
| 落ちてくるどんぐり | 大木の下(ゴールから 6m 以内) | 数えている間と見張りの間に、ときどき落ちてくる。地面に影が出てから **0.8秒** で落ちる。当たると **0.8秒** ひるむ(戻されはしない) | ゴール前の最後の駆け引き。影を見て止まるか突っ走るか |

## 観客

コースの両脇の切り株や根っこの上に、森の小動物が並んで見ている。

- リス、ハリネズミ、コマドリ、モグラ(穴から顔を出す)
- 数えるのに合わせて体を揺らす。誰かが見つかると「あっ」と驚く(笑う子もいる)。ゴールで拍手してはねる。

## 流れ(1回 30〜40秒。制限時間は60秒)

1. **よーい**(2秒)
2. **かぞえる**: 先生が「だ・る・ま・さ・ん・が・こ・ろ・ん・だ」と数える。字幕で1文字ずつ光る。
   - 数える長さは毎回ちがう(1.6〜4.5秒)。
   - ときどき途中で止まる(フェイント)。止まっても振り向かない。
3. **ふりむく**(0.3秒): 首が回る。この間は判定しない。
4. **みはる**(2〜3秒): 動いている人は見つかる。
   - 振り向き終わってから **0.2秒は判定しない**(反応と通信の遅れを吸収する)。
   - 見つかった人は目を回して **5m 戻され**、1.5秒動けない。スタートまで戻すと差がつきすぎる。
5. **もどる**(0.3秒)→ 2 にもどる。
6. **おしまい**: 誰かがゴールに触れたら終わり。60秒たったら、そこまでの距離で順位を決める。

## 操作

- **長押し**(PC はスペースキー)で走る。0.3秒ほどで最高速になる。
- **離す**と止まるが、**0.15秒ほど勢いで滑る**。早めに止まるか、ぎりぎりまで粘るかが駆け引き。

## CPU

- 字幕の進み具合を見て、決めたところで手を離す。
  - しんちょう: 早めに止まる / ふつう / つよき: ぎりぎりまで走る
- 走り出しと止まるときの反応に、ばらつきを入れる。たまに止まりそこねる。
- フェイントで数えるのが止まったら、驚いて止まることがある。

## 画面

- カメラは自分のキャラのうしろ。5人とゴールの先生が1画面に入る。
- 上: 字幕(だるまさんがころんだ)と残り時間。横: 5人の進み具合。
- 下: 大きな「長押しではしる」ボタン(画面のどこを押してもよい)。
