# だるまさんがころんだ

見張り番がうしろを向いているあいだに進み、振り向いたら止まる。いちばん早くゴールに触れた人の勝ち。

## 場面

- まっすぐの草原コース(20m)に5レーン。ゴールに見張り番の「ホーホー先生」(フクロウ)が立つ。
- 先生は体をうしろに向けたまま、**首だけぐるっと回して振り向く**。

## 流れ(1回 約60秒)

1. **よーい**(2秒)
2. **かぞえる**: 先生が「だ・る・ま・さ・ん・が・こ・ろ・ん・だ」と数える。字幕で1文字ずつ光る。
   - 数える長さは毎回ちがう(1.6〜4.5秒)。
   - ときどき途中で止まる(フェイント)。止まっても振り向かない。
3. **ふりむく**(0.3秒): 首が回る。この間は判定しない。
4. **みはる**(2〜3秒): 動いている人は見つかる。
   - 振り向き終わってから **0.2秒は判定しない**(反応と通信の遅れを吸収する)。
   - 見つかった人は目を回して **5m 戻され**、1.5秒動けない。スタートまで戻すと差がつきすぎる。
5. **もどる**(0.3秒)→ 2 にもどる。
6. **おしまい**: 誰かがゴールに触れたら終わり。60秒たったら、そこまでの距離で順位を決める。

## 操作

- **長押し**(PC はスペースキー)で走る。0.3秒ほどで最高速になる。
- **離す**と止まるが、**0.15秒ほど勢いで滑る**。早めに止まるか、ぎりぎりまで粘るかが駆け引き。

## CPU

- 字幕の進み具合を見て、決めたところで手を離す。
  - しんちょう: 早めに止まる / ふつう / つよき: ぎりぎりまで走る
- 走り出しと止まるときの反応に、ばらつきを入れる。たまに止まりそこねる。
- フェイントで数えるのが止まったら、驚いて止まることがある。

## 画面

- カメラは自分のキャラのうしろ。5人とゴールの先生が1画面に入る。
- 上: 字幕(だるまさんがころんだ)と残り時間。横: 5人の進み具合。
- 下: 大きな「長押しではしる」ボタン(画面のどこを押してもよい)。
