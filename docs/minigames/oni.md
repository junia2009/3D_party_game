# 夕ぐれの 森の おにごっこ

夕日の 森の 丸い 原っぱで、5人で おにごっこ。1人が おに(赤い つの)。タッチされたら おにが 交代。
60びょうで「おにで なかった 時間」が いちばん 長い 子の 勝ち。

## ルール(`src/games/oni/rules.js`)

- 60びょう(はじめに 3びょうの よーい)。さいしょの おには くじ。おには まん中の 切り株の 前から、ほかの 子は まわりから(立ち位置も くじ。場所で にげやすさが ちがう ので)。
- 走る: スティックの 向きへ。たおすほど はやい。にげる 子 3.3、おに 3.75(すこし はやい)。
- ダッシュ: おした 瞬間に 0.55 びょう 1.75 ばいの はやさ。つかったあと 3.2 びょうは つかえない。
- タッチ: おにと 中心が 0.95 より 近いと タッチ。いちばん 近い 子が つぎの おに。
  - 新しい おには 1.1 びょう 動けない(そのあいだに みんな にげる)。前の おにを 3 びょうは タッチ できない(タッチ返しなし)。
- 木・切り株は とおれない。広場(半径 9.5)の ふちからは 出られない。にげる 子どうしは かるく おしあう(おには すりぬける)。
- かくれ草むら: 5つ。中に いる あいだは かくれる(ほかの 子の 画面では うすく、CPU の おには 近くで ないと 気づかない)。
- 金の どんぐり: 5〜8 びょうごとに 落ちてくる(同時に 2つまで、12 びょうで 消える)。ひろうと +2点(おにでも ひろえる)。
- 点 = おにで なかった 時間(びょう)+ どんぐりの ボーナス。
- 順位: 点 → つかまった 回数が 少ない → 席。

## CPU(`src/games/oni/cpu.js`)

- 人と おなじく スティックの 向きと ダッシュだけ。react びょうごとに 考えなおす。木・切り株は よけて、ふちでは 内がわへ まげる。
- おに: 近い・ふちに いる 子を ねらって、すこし 先を よんで 走る。草むらの 子は 近くで ないと 気づかない(だれも 見えなければ 草むらを のぞきに いく)。とどきそうなら ダッシュ。
- にげる: おにが 遠い ときは 金の どんぐりを ひろう・草むらで 休む。近い ときは はなれる 向きへ(ふちでは 横へ まわりこむ)。すぐ そばに 来たら ダッシュ。
- 性格: しんちょう(早めに にげる、草むら 好き)/ ふつう / つよき(ぎりぎりまで どんぐりを ねらう)。

## 画面(`src/games/oni/game.js`, `stage.js`)

- 会場: 夕日の 森の 丸い 原っぱ。まん中に 大きな 切り株(旗と きのこ)。木・小さな 切り株・草むら(花つき)。
  ふちは 丸太の さくと ちょうちん。外は 森の 木と 山の かげ。
- 木の 葉っぱは、うしろに だれか いると うすく なる(上から 見る カメラで かくれない ように)。
- おには 頭に 赤い つの、足もとに 赤い 輪と 光。タッチで「タッチ!」と 星、自分が おにに なると 画面の ふちが 赤く。
- カメラは 自分の まわり(広場の まん中へ すこし よせる)を 上から。
- 操作: どこでもスティック + 右下の ダッシュ(つかったあとは 輪が たまる)。パソコンは 矢印 / WASD + スペース。
- 曲は かけっこ(`kakekko`)。
