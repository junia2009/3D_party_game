# どんぐりマンション だっしゅつ

大きな木の幹の中の 6 かいだての どんぐりマンション。5人は 6かいから、1かい(じめん)の出口をめざす。
どの階も、ろうかの奥に ドアが ならぶ。下へ行ける ただしいドアを 見つけて、いち早く だっしゅつした子の勝ち(30〜60 秒)。

## ルール(`src/games/dasshutsu/rules.js`)

- 階は 6かい(floor 5)→ 1かい(floor 0)。ドアの数は 6かい 3・5かい 4・4かい 4・3かい 5・2かい 5。
- ろうか: x は ±5.2m、z は 0(ドアの かべ)〜2.2m。走る速さ 3.4m/秒。同じ階の子どうしは ぶつかる。
- ドアの前(x で 0.7m 以内、かべから 1m 以内)で「あける」を おすと 入る(0.45 秒)。
  - ただしいドア(1つ): かいだんを おりて(0.9 秒)、下の階の はしの かいだんから 出てくる(階ごとに 右はし・左はし)。
  - まちがいのドア: ふしぎ! 1.1 秒後に 同じドアから 出てくる。0.45 秒「あれれ?」で うごけない。
  - すべり台(ちか道): 4かい・3かいに ときどき(45%)。2かい ぶん 下りる。
  - 上へのかいだん(まちがい): 6かい以外に ときどき(40%)。ひとつ上の階へ もどされる。
- ヒントの印: 6かい以外の いくつかの階(60%)で、5 秒ごとに 0.7 秒、ただしいドアの上に どんぐりの印が 光る。
- 1かいに ついたら ゴール。ゴールした順が 順位。まだの子は 低い階ほど上。
  3人(2人のときは 1人)ゴールして のこりが 2人以下になったら おしまい。100 秒で時間ぎれ。

## CPU(`src/games/dasshutsu/cpu.js`)

- 自分で ためした ドアは おぼえる(階ごとに。上へ もどされても わすれない)。
- 同じ階の ほかの子が ドアに入って どうなったか、ある確率で 見ている(下へ行けた → そこへ / 出てきた → ちがう)。
- ヒントの印に ある確率で 気づく。わからないときは、まだ ためしていない 近いドアへ(ときどき 気まぐれ)。
- 性格: しんちょう(よく見ている・あけるまで ゆっくり)/ ふつう / つよき(見ていない・すぐ あける)。

## 画面(`src/games/dasshutsu/game.js`, `stage.js`)

- 会場: 大木の幹の中の アパートを、手前の かべが ない 切り口(ドールハウス)で見せる。うしろ半分の幹、
  切り口の木の色の帯、根、てっぺんに 幹のふたと 葉っぱの しげみ、まわりは 草地と森。
  階ごとに かべ紙の色が ちがい、どんぐり もようと 階の札(6F〜1F)、かべのランプ。
  ドアは 上が まるい木の戸(色は いろいろ)で、番号の札と ノブ。階の はしに かいだん。1かいは ロビーと「でぐち」。
- ドア: 入るときと、まちがいで 出てくるときに 開く。まちがいの ドアや 上へのかいだんの上には 赤い ×(ほかの子にも分かる)。
- ヒントの印: ただしいドアの上に 金の光(自分の階なら キラン)。
- カメラ: 自分の階を 前から(上下の階も 少し見える)。ゴールしたら マンションぜんたいを 引いて見せる。
- ゴールした子は 1かいの ロビーに ならんで よろこぶ。
- HUD: 上に みんなの階(ゴールしたら 順位)、右上に 自分の階、右下に「あける」(ドアの前で 光る)。
