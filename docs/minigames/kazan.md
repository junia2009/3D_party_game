# 火山の 落ちものよけ

夕焼けの 火山の ふもと、ようがんの 海に つきでた まるい 岩の 台。空から 岩や 火の玉が ふってくる。
影を 見て よけ、転がる 岩は ジャンプで とびこえる。最後の 1人まで のこった子の 勝ち(勝ちぬき・40〜60 秒)。

## ルール(`src/games/kazan/rules.js`)

- 台: 半径 5m。まん中 2m は くずれない。外がわは 2本の 輪(12 と 9 の 扇形の かけら)。
- 動く: スティックで 走る(3.3m/秒)。ジャンプ(空中で 0.7 秒くらい)。子どうしは 押しあう。
- 落ちもの: 落ちる ところに 先に 影(予告)。当たったら 脱落(空中でも 1.5m より 低ければ 当たる)。
  - 岩 rock(半径 0.6・予告 1.15 秒)/ 大岩 big(半径 1.25・予告 1.7 秒)/ 火の玉 fire(半径 0.55・予告 1.0 秒。落ちた あと 2.2 秒 火が のこる。火に 入ると 脱落、ジャンプ中は だいじょうぶ)。
  - 45% は だれかを ねらって(少し ずらして)落ちる。
- だんだん 激しく: 50 秒かけて、落ちる 間かくが 1.05 秒 → 0.32 秒に。大岩と 火の玉が ふえ、予告も 少し みじかく なる。
- 転がる 岩: 12 秒目から 7〜4 秒ごとに、台の ふちから 反対がわへ 転がってくる。足が 0.42m より 上なら とびこえられる。
- 足場が くずれる: 18 秒目から 1.6 秒ごとに、外の 輪の かけらが ぐらぐら(1.5 秒)→ くずれる。内の 輪は 半分だけ くずれる。
  足場の ない ところに 立つと 落ちて 脱落。
- おたすけの かさ: 7 秒目から 9〜14 秒ごとに 台の 上に 落ちている(8 秒で 消える)。ひろうと 7 秒、1回だけ 当たっても だいじょうぶ(転がる 岩は くだける)。
- 70 秒で 時間ぎれ。順位: のこった子(まん中に 近い 順)、そのあとは 脱落が おそかった順。

## CPU(`src/games/kazan/cpu.js`)

- 0.15 秒くらいごとに、まわりの 行き先(3つの きょり × 16 方向)から いちばん 安全な ところを えらんで 走る。
  気づいた 影・火・転がる 岩の 通り道・ぐらぐらの 足場・台の ふちを さけ、かさに ひかれる。通り道に 穴が ある 向きには 行かない。
- 影に 気づくまで react 秒。転がる 岩には、ぶつかる 少し前に ジャンプ(jumpSkill の わりあいで 成功)。
- 性格: しんちょう(大きく よける・かさに あまり ひかれない)/ ふつう / つよき(気づくのは 早いが よけが ぎりぎり・かさが 大すき)。

## 画面(`src/games/kazan/game.js`, `stage.js`)

- 会場: 夕焼けの 空、けむりの 火山(ようがんの すじ・赤く 光る 火口)、遠くの 山なみ。ようがんの 海から とがった 岩が つきでる。
  台は 黒っぽい 岩(ひびと 小石)で、かけらの あいだに われめ。
- 落ちもの: 影が だんだん こく 大きく なり、さいごの 0.55 秒で 空から 落ちてくる。落ちると 土けむり(大岩は 大きく・画面が ゆれる)、火の玉は 火の粉。
- 火の あと: こげあとの 上で 火が ゆらゆら。転がる 岩は くるくる 回る。かさは ふわふわ 回って、消えそうに なると ちかちか。
- かさを もっている 子は 頭の上に 自分の 色の かさ。ふせいだら「セーフ!」。
- 当たった 子は ぽーんと とんで ようがんへ(火の粉)。足場から 落ちた 子は ひゅ〜っと 落ちる。
- カメラ: 手前の 上から 台ぜんたいを 見おろす。
- HUD: 上に のこっている子(かさを もっていると 金の わ)と のこり時間。どこでも スティックと、右下に「ジャンプ」。
