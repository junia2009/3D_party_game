# 森の図書館の ぱらぱらブック

木の 図書館の 机に ひらいた 大きな 絵本。奥に 立った ページが、手前へ ぱたんと たおれてくる。
ページには 穴が あいていて、たおれた とき 穴の ところに いれば セーフ、外に いたら ぺちゃんこで 脱落。
めくれる 速さが だんだん 速くなる 耐久戦(しかけは 速さだけ。シンプルに)。最後まで 残った 子の勝ち(40〜70 秒くらい)。

## ルール(`src/games/ehon/rules.js`)

- 床(手前の ページ)は よこ 7.6m・おく 6.6m。本の ふちから 0.35m の 内がわを 走れる(外へは 出られない)。
- ページの 穴: はじめの 3まいは 4つ、そのあとは 2〜4つ(くじ)。どんぐり・葉っぱ・星・花・キノコの 形(当たりは 半径 1m の 円)。穴どうしは 重ならない。
  体の 中心が 穴の ふちから 0.18m 内がわなら セーフ。
- 立っている ページの 穴は、たおれると 床の 同じ よこ位置・「高さ = 手前への きょり」に 来る(上の 穴ほど 手前)。
- めくれる 速さ: ページが 立ってから たおれはじめるまで はじめ 3.2 秒、1まいごとに 0.16 秒 短く(さいごは 0.45 秒)。
  たおれる 時間は 0.7 秒から 0.3 秒まで。たおれた あと 0.35 秒で 次の ページ。
- 走る: どこでもスティック(3.4m/秒)。ぶつかると おしあう(穴の とりあい)。
- 150 秒たっても 決まらなければ、穴の まん中に 近い順。
- 順位: のこった 子、そのあとは ぺちゃんこに なったのが おそい順(同時なら 穴から 遠い 子が 下)。

## CPU(`src/games/ehon/cpu.js`)

- 新しい ページが 立ったら 少し おくれて(0.3〜0.5 秒)穴を 見る。近くて すいている 穴へ。ときどき 見まちがえて となりの 穴へ 行きかける。
- 穴が こんでいて(2人)、まだ 間に あいそうなら ほかの 穴へ。
- 性格: しんちょう(こんだ 穴を さける)/ ふつう / つよき(こんでいても 気にしない)。

## 画面(`src/games/ehon/game.js`, `stage.js`)

- 会場: 木の 図書館。奥に 本棚、机の 上に 大きな 絵本(赤い 表紙)。ランプの あたたかい 光、インクと 羽ペン、つみあげた 本。
- ページ: 紙の 色に 森の 絵と 文字の 行、上に ページ番号。穴は こげ茶の ふちで 切りぬき(むこうは こい 色)。
- 床の 影: たおれてくる 穴の 場所だけ 明るく、金の 点線の ふち。ページが たおれてくるほど 影が こくなる。
- たおれる: だんだん 速く(ひゅっ)、ぱたんで 画面が ゆれて 紙の ほこり。セーフの 子は ばんざい。
- ぺちゃんこ: ぺたんこに つぶれて、紙きれ みたいに ひらひら 飛んでいく。
- HUD: 上に みんなの 札と「○まいめ」。5まいごとに「はやく なるよ!」、10まいめから 画面の ふちが オレンジ。
- のこり 2人で「いっきうち!」(ドロドロ)と カメラが 寄る。決着は 勝った 子へ 寄って 紙ふぶき。
