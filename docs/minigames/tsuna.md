# 川原の つなひき

小川を はさんだ 川原で、3人 対 3人の つなひき。5人を くじで 左右に 分け、たりない チームには 森の なかま(すけっと)が入る。
「よいしょ!」の 合図に あわせて タップして、相手の チームを 小川に ひきこんだら 勝ち(20〜40 秒)。

## ルール(`src/games/tsuna/rules.js`)

- チーム: 席を まぜて こうごに 左(L)・右(R)へ。3人に たりない チームには すけっと(リス・ハリネズミ・コマドリ)が入る。
  すけっとの 力は 0.8 倍で、うでまえは ふつうくらい(ルールの乱数で 決める)。
- 「よーい」3.2 秒のあと、合図(ビート)が 0.85 秒ごと。タップは ビートとの ずれで 力が きまる。
  - ぴったり(±0.09 秒)1.0 / いいね(±0.18 秒)0.72 / ずれた 0.18。
  - 同じ ビートで 2回目より あとの タップ(連打)は 0.05 だけ(3回まで)。
- つな: 力の差 × 0.55 が いきおいに なり、だんだん おさまる(damp 2.0)。目じるしが 1.6m 来たら 勝ち。
  40 秒で 時間ぎれ(目じるしが よっているほうの勝ち)。
- せーのの ふいうち: ふつうの リズムが 6〜9 拍 つづいたあと、4 拍だけ 速く(0.62 秒・65%)か ゆっくり(1.15 秒)。
- すべる どろ: ひとりずつ 7〜12 秒ごとに つるっ。0.7 秒の うちに タップすれば ふんばれる。まにあわないと 1.3 秒 引けない。
- うしろから 応援: 目じるしが 自分がわへ 0.5m より 来ていると、力が ふえる(負けが こむほど、さいだい +35%)。
- 順位: 勝った チームの子を よく引いた順、そのあと 負けた チームの子を よく引いた順。

## CPU(`src/games/tsuna/cpu.js`)

- つぎの ビートを ねらって タップ。ずれ方は 性格しだいで、リズムが かわった すぐあとは 1.8 倍 ずれる。
- すべったら、react 秒で ふんばる(ときどき まにあわない)。
- 性格: しんちょう(ずれが 小さい・連打しない)/ ふつう / つよき(ときどき ついでに 連打)。

## 画面(`src/games/tsuna/game.js`, `stage.js`)

- 会場: 手前から奥へ ながれる 小川(平たい石・水面が 流れる)と、左右の 草の川原(小石・草花)。まわりは 森。
  奥の 岩の上に ホーホー先生(合図で はばたく)。観客は 左右うしろの 切り株の上。
- つなの まん中に 赤い 目じるし。勝ちの 線に 白い旗。みんな 小川のほうを 向いて のけぞって 引く。
- すべったら のけぞって ばたばた、まにあわないと ころぶ。
- 決着: 負けた チームは 小川へ ずるずる → ざぶん(しぶき)。勝った チームは こちらを 向いて よろこぶ。紙ふぶき。
- カメラ: 横から。つなの 目じるしを 追って 左右に ずれる。
- HUD: 上に 左右の チームの札(自分の チームは 白)と のこり時間、その下に つなの 目じるしの メーター、
  負けている チームに「おうえん!」。下に リズムの 輪(ちぢんで 重なったら タップ)と「よいしょ!」。
