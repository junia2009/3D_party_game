# どんぐり早うち

夕焼けの岩場で、5人が横一列にならんで どんぐり鉄砲をかまえる。
ホーホー先生が黄色い「どんぐりの旗」をあげたら、いちばんに うつ。勝ちぬきで、最後まで残った子の勝ち(30〜60 秒)。

## ルール(`src/games/hayauchi/rules.js`)

- 1回の流れ: かまえて(1.6 秒)→ じっと待つ → 合図(黄色い旗)→ 判定(2.8 秒)。はじめの回の前に 2 秒、会場を見せる。
- 待つ時間は毎回ちがう(1.8〜4 秒。2回目からは 22% で 4.8〜6.8 秒の「じらし」)。
- 合図より前に うつと「おてつき」(かまえているあいだも)。おてつきした子は、みんな脱落。
  おてつきがいなければ、いちばん遅かった子が脱落(同じ速さなら くじ)。
  のこりの子が全員おてつきしたら、だれも脱落せず やりなおし。
- 合図のあと 1.5 秒たっても うたなかったら、1.5 秒で うったことにする。
- 待っているあいだの ひっかけ(はじめの回は じゃまものだけ。回が進むと増える。1回に 3 つまで):
  - にせの合図: 先生が黄色い旗を半分あげて やめる / 「どん…ぐりぃ…」と言いかける。
  - じゃまもの: 転がってくる草のまり / 横切るカラス。
  - 逆: 赤い旗(×)「うつな!」。合図そっくりに出るが、うったら おてつき。
  - 2回続けて やりなおしになったら、つぎの回は ひっかけなし(終わらなくならないように)。
- 順位: 勝った子、そのあとは脱落がおそい順。同じ回に何人か おてつきしたら、早く うってしまった子ほど下。
- 結果には「いちばん速いとき(秒)」と おてつきの数を出す。

## CPU(`src/games/hayauchi/cpu.js`)

- 合図を見てから 反応時間(毎回ばらつく)で うつ。ひっかけを見ると、ある確率で つられる。
- 長く待たされると、まれに がまんできずに うつ(じらしに弱い)。
- 性格: しんちょう(反応 0.33 秒・つられにくい)/ ふつう(0.30 秒)/ つよき(0.27 秒・つられやすい・じらしに弱い)。

## 画面(`src/games/hayauchi/game.js`, `stage.js`)

- 会場: 赤い砂の荒れ地。うしろに しまもようの岩山がならび、夕日。サボテン・岩・かれ木。
  5人の前の木の柵に、ひとりひとつ ブリキのかん(帯がその子の色)。まん中の奥の高い岩の上に ホーホー先生。
  先生は右手に黄色い旗(どんぐりの絵)、左手に赤い旗(×)。ふだんは ななめ下に持ち、合図で まっすぐ上へ。
  観客は左右のたるの上。
- かまえ: 両手で どんぐり鉄砲を前へ。うつと どんぐりが飛んで、かんが はね飛ぶ(カーン)。
  おてつきは どんぐりが あさっての方へ飛んで 地面でぽふっ、目を回す。
- 合図の瞬間: 先生が羽ばたいて旗をあげ、「パーン!」、画面が光って「うて!」。逆は赤く光って「うつな!」。
- 待っているあいだは 胸の音(ドクン…)が だんだん速くなり、カメラが じわっと寄る。
- 判定: いちばん速い子に「いちばん!」、脱落した子は目を回して うしろへ下がり、こちらを向く。
- HUD: 上に みんなの札(うった秒・おてつき・×)。
- 決着: 勝った子が前へ出てきて よろこぶ。紙ふぶき。
- 操作: 画面のどこでもタップ。パソコンはスペース / エンター。
