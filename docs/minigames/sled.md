# 落ち葉そりレース

紅葉の山道を、落ち葉のそりで5人いっしょにすべりおりる。先にゴールした人の勝ち。1位で 30 秒くらい。

## 場面: 紅葉の山道

- 赤・だいだい・黄の紅葉の木にかこまれた、落ち葉のじゅうたんの坂道(320m)。
- 道の両がわのふちは落ち葉の山(こするとめりこんで遅くなる)。
- スタートとゴールに木の門。ゴールの門の上にホーホー先生、まわりに観客。
- 時間帯(朝・昼・夕方)は遊ぶたびに変わる。

## 動かし方

- 画面の**左半分**を押しているあいだ左へ、**右半分**で右へ。**両方**押すと伏せて速くなる(そのあいだは曲がれない)。
- 指は画面の下のすみに置くだけでよい。下の左右に、押しているほうが光るしるし。
- パソコンは ← → / A D、伏せるのは ↓ / S(または ← → 両方)。

## ルール

- 坂で速くなり、空気の抵抗で頭打ち(ふつう 10m/秒、伏せると 12m/秒くらい)。
- **カーブ**では外がわへ流される(速いほど強く)。**内がわほど道のりが短い**。
- **ふち・しげみの島**にこすると遅くなる。
- **キノコのジャンプ台**: 乗ると大きく飛んで、少し速くなる。空中では曲がりにくい。
- **どんぐり**: 一列に並んでいる。拾うと少しのあいだ速くなる(1こ 0.6 秒、最大 2 秒)。
  どんぐりは子ごとにある(取り合いにしない)。自分の画面には自分のぶんだけ見える。
- **わかれ道**: 右カーブのとちゅうに、しげみの島。右(内がわ)は幅 1.4m のせまい近道、
  左(外がわ)は広い遠回りで、どんぐりの列とジャンプ台がある。
- **そりどうし**: 横にならぶと押しあう。うしろからぶつかると、うしろの子が少し遅くなる。
- **スタートの並び**はレースごとにくじで決める(最初のカーブの内がわが得をするので)。
- 1人めがゴールしてから 10 秒で終わり。順位はゴールした順、ゴールしていない子は進んだ道のりの順。

## CPU

人と同じく「左・右・両方・はなす」しか押せない。前方のどんぐりの列・ジャンプ台・カーブ・わかれ道を見て、
ねらう横の位置を決めて押す。考えなおすのに間があり、ねらいが少しずれる。まっすぐで何もなければ、いまの位置のまま。
すぐ前にだれかいたら、横へずれて追いこす。

テスト(`test/sled.test.js`)で、決着・席のかたより・人くらいの反応でも互角に戦えることを見張る。
