# まつぼっくり的あて

森の池のほとりの桟橋に5人がならび、池の向こうに出てくる「自分の色の的」へ、まつぼっくりを投げる。
45 秒で、いちばん点の多い人の勝ち。

## 場面: 森の池のほとり

- 手前の岸に木の桟橋。5人が横にならぶ(自分はまん中。カメラは自分の右肩のうしろ・上から)。
- 池にはハスの葉と花、岸にはガマとアシ。向こう岸は草の土手。まわりは森。
- 池の上に、両がわの大きな木から木へ、**つるの綱**が2本(手前 10.5m・奥 14.5m)。つるされた的とハチの巣はここから下がる。
- 時間帯(朝・昼・夕方)は遊ぶたびに変わる。

## 動かし方(ぱちんこ)

- 画面のどこかに指をおいて、**下へひっぱって、はなす**。ひっぱる長さで強さ(遠さ)、**左へひっぱると右へ**飛ぶ。
- ひっぱっているあいだは、飛ぶ道すじ(**風なし**)の点線と、落ちるところの輪が見える。風は自分で読む。
- 少しだけ引いてはなすと、投げるのをやめたことになる。
- パソコンは ← → / A D でねらい、スペースを長押しで強さをためて、はなすと投げる。

## ルール

- 的は**子ごとにある**(取り合いにしない)。出てくる場所・時間はみんな同じで、自分から見た位置も同じ(公平)。
  自分の画面には自分の的だけが見える。
- 的の種類:

  | 的 | 点 | 出るところ |
  | --- | --- | --- |
  | ハスの葉の的 | 1 | 池の手前〜まん中。ゆっくりただよう |
  | 切り株の的 | 2 | 向こう岸(17〜21m) |
  | つるされた的 | 2 | つるの綱から下がって、ゆれる |
  | 金の的 | 5 | トンボが運ぶ。小さくて、左右に大きく動く |
  | ハチの巣 | -3 | つるの綱から下がる。当てると 1.6 秒投げられない |

- **風**: 6〜10 秒ごとに横風が変わる(なぎのときもある)。遠くへ投げるほど大きく流される。上の札に向きと強さ。
- **れんぞく**: 外さずに当てつづけると、3つめから +1、6つめから +2。池に落とす・ハチの巣に当てると 0 にもどる。
- 投げたあと 0.55 秒は、次を投げられない。
- 順位は 点数 → 当てた数 → 席の順。

## CPU

人と同じく「どの向きへ、どれだけ強く」だけを出す。的に気づくまでの間、ねらいのぶれ(遠いほど大きい)、
風の読みちがい、動く的の先読みの甘さを持つ。ハチの巣はねらわない。

テスト(`test/mato.test.js`)で、決着・点数の計算・公平さ・ねらいの計算・風・れんぞく・
席のかたより・人くらいの反応でも互角に戦えることを見張る。

## 演出と音

- **的**(`targets.js`): 種類ごとに出かたがちがう(ハスの葉は水から・切り株は土から・綱の的は降りてきて弾む・金の的はトンボが運ぶ)。
  もうすぐ引っこむ的は小きざみにゆれる。当たると板がまっぷたつに割れる。ハチの巣に当てるとハチがこちらへ飛んでくる。
- **ぱちんこ**(`sling.js`): 右手で右前に構え、左手でゴムを引く。はなすとゴムがばねでふるえる。足もとのかごから次を取る。
- **池**(`pond.js`): 水面のうねり・深さの色・さざなみ。風でガマとアシがしなり、水面に白い筋、木の葉が飛ぶ。
  手前のつるの綱に**吹き流し**(なぎで垂れ、強い風でぴんと横へ)。ときどき魚がはねる。
- **音**(すべて WebAudio): ひっぱるとゴムがきしむ(引くほど高く)・はなすとばちん・当たるとコーン(れんぞくでドレミと上がる)・
  池にぽちゃん・ハチのぶーん・的が出る小さな音。まわりは水のたぷたぷ・風(強さで)・ときどき小鳥。
- のこり5秒は時計が赤く脈打ってチクタク鳴る。れんぞく3つ以上は画面のふちが金色に光る。
