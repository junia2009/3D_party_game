# 森の学校の けしごむ大戦

どんぐりの 森の 教室の つくえの 上で、自分の けしごむを はじいて ほかの けしごむを おとしあう。
けしごむの 上には キャラが のって いる。さいごまで のこった 子の 勝ち。

## ルール(`src/games/keshigomu/rules.js`)

- よーい 3 秒 → たたかい(さいごの 1こに なるか、80 秒で おわり)→ 2.6 秒 見る。
- つくえ: はば 14・おくゆき 9.5。20 秒から 65 秒に かけて、はしから けずれて 40% の 大きさまで せまく なる。
- はじく: けしごむが とまって いる(はやさ 0.35 いか・回り 1.2 いか)ときなら いつでも。
  - おして いる あいだ ためる(0.9 秒で いっぱい)。はなすと とぶ。はやさは 2.5〜9(ためた ぶん)。
  - 向き(aim)は じぶんで きめる。ひねり(spin -1〜1)を 入れると 回りながら すべり、回って いる あいだ すこし まがる。
  - はじいた あと 0.35 秒は つぎを ためられない。
  - ためて いる とちゅうで ぶつけられると ためは きえ、いちど はなすまで ためられない。
- けしごむの かたち(キャラで きまる。おもさと すべりが ちがう)。かたちは 円の くみあわせ:
  - まる(ミミ・ペンネ): 円 1つ。かるく、よく すべる。
  - しかく(コンコ・レイ): 円 4つ。
  - ながしかく(ゴンゾ・キリコ): 円 3つ。おもく、すべらない。
  - どんぐり(ポン太・ケロスケ): 大きい 円と 小さい 円。
- うごき: つくえとの まさつで だんだん おそく なる(かたちで ちがう)。回りも まさつで とまる。
- ぶつかり: 円どうしで しらべる。はねかえり 0.45、こすれ 0.25(ずれて あたると 回る)。おもさと 回りにくさ(慣性)を つかう。
- おちる: けしごむの まんなかが いまの つくえの そとに 出たら おちる。3 秒 いないに ぶつけた 子が「おとした 子」。
- 順位: のこった 子(まんなかに ちかい 順)→ おちるのが おそかった 順 → 席。

## CPU(`src/games/keshigomu/cpu.js`)

- 人と おなじく「おす(ためる)・向き・ひねり」だけ。見て いるのは つくえの 上の 位置と 大きさ。
- とまったら すこし 考えて ねらう 相手を きめる: まっすぐ おしたとき 相手が つくえの はしまで ちかいほど よい。
  自分が はしに ちかすぎる ときは まんなかへ もどる ことも ある。
- ためる 強さは、相手が はしまで すべる はやさを 見つもって きめる。はずれて 自分が おちそうなら しんちょうな 子は やめる。
- 向きと 強さは ずれる。ひねりは ときどき。
- 性格: しんちょう(よく 考えて、おちない ように)/ ふつう / つよき(つよく はじく)。

## 画面(`src/games/keshigomu/game.js`, `stage.js`)

- 会場: 森の 学校の 教室。大きな 木の つくえ(天板は 小さな 板の ならび)、黒板、まど、ほかの つくえ。
- けしごむ: 白い ゴムに プレイヤーの 色の 紙の スリーブ。上に キャラが のる(ふだんは カメラを 見て、ためる ときは ねらう 向き)。
- ためると まわりに わが のびて いく。ねらいは 点線で、どこまで すべるか(ひねりの まがりも)を 見せる。
- ぶつかると 星が とんで、つよい ときは 画面が ゆれる。おちた けしごむは くるくる 回って 下へ。
- つくえが せまく なる ときは、もうすぐ くずれる 板が 赤く 光って から、ぽろぽろ おちる。
- カメラ: 上から つくえ ぜんたい(たてもちは つくえの ながい ほうを たてに)。せまく なると 寄る。
- 操作: 画面の どこでも おして ひっぱる(パチンコの ように)。はなすと はじく。ゆびを まげて ひくと ひねり。
  ひっぱらずに はなすと いちばん ちかい 子へ。パソコンは ←→ で 向き、スペースで ためる、Q/E で ひねり。

### 演出

- ためると のって いる 子が ちぢこまり、いっぱいで ぷるぷる。はじくと うしろから ゆびの 絵が はじき、のって いる 子は のけぞる。
- すべった あとに こすれた すじと けしかす。ひねりで 回って いる あいだは くるくる 線。
- つよく ぶつかると 星と「ゴン!」「ドカッ!」。くずれる 板からは 木くず。おちた けしごむは ゆかで はねて ころがって とまる。

### 盛り上げ

- おとすと「○○が △△を おとした!」。おとした かずは 上の なまえに ★。
- のこり 2人で「いっきうち!」(画面の ふちが 赤く 光る)。
- 決着: 勝った 子は 王冠を のせて けしごむの 上で はねる。紙ふぶきが つづけて ふり、カメラは 勝った 子の まえへ 回りこんで、うしろの 黒板まで 見わたす。
