# 空まで まめのきジャンプ

森の 広場から 空へ のびる 5本の まめの木。それぞれ 自分の 木を、生えてくる 葉っぱを テンポよく 乗りついで のぼる。
40 秒で いちばん 高く のぼった 子の 勝ち。反射神経の 勝負。

## ルール(`src/games/mame/rules.js`)

- いま 乗っている 葉っぱの 上に、つぎの 葉っぱが 左か 右に 生える(ならびは みんな 同じ。同じ 側は 4まい まで)。
- 生えた ほうの ボタンを おすと 1まい 上へ(とびうつる 0.16 秒は おせない)。
- まちがえた ほうを おすと 2まい 下へ すべり落ちて、0.65 秒 動けない。
- 金の まめ: 12まい目から ときどき 葉っぱに ついている。乗ると 3.5 秒、1回で 2まい ぶん のぼれる(つぎに おすのは 2まい 先の 葉っぱの 側)。
  先に 着いた 子の もの(あとの 子の 木には もう ない)。
- 順位: 40 秒 たった ときの 高さ → 同じなら 先に その 高さへ 着いた 子。

## CPU(`src/games/mame/cpu.js`)

- 葉っぱに 乗ったら、つぎの 葉っぱを 見て 0.24〜0.39 秒 おくれて おす。ときどき まちがえる。
- だんだん 手が はやくなるが、まちがいも ふえる。
- 性格: しんちょう(おそいが まちがえない)/ ふつう / つよき(はやいが まちがえやすい)。

## 画面(`src/games/mame/game.js`, `stage.js`)

- 会場: 森の 広場から 空へ、ねじれた みどりの つるの まめの木が 5本。自分の 木が まん中。上へ いくほど 雲が ふえる。25まいごとに 高さの 札。
- 葉っぱは ハートの 形。つぎの 葉っぱは ぷくっと 生えて、明るい 色。金の まめは くるくる 回る。
- とびうつる: ぴょんと 弧を えがいて、のぼるほど 音が 高く。まちがえると 葉っぱが ちって すべり落ちる(ふらふら)。
- カメラは 自分の 高さを 追う。決着は いちばん 高い 子へ 寄って 紙ふぶき。
- HUD: 上に みんなの 高さ(まい)と のこり時間、下に 左右の 大きな ボタン(あたりで 金、まちがいで 赤)。画面の 左半分 / 右半分 を タップしても いい。
