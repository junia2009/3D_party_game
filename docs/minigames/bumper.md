# 遊園地の バンパーカー

たそがれの 遊園地。屋根つきの 丸い リンクの上で、5台の バンパーカーが ぶつけあう。
リンクの ふちから 出たら 脱落。最後まで 残った 子の勝ち(30〜45 秒くらい)。

## ルール(`src/games/bumper/rules.js`)

- リンクは 半径 6.5m。中心が ふちから 0.05m 出たら 落ちる。
- 走る: スティックの 向きへ ハンドルを きる(1 秒に 3.3 ラジアン まで)。車は **前へ しか 進まない**。
  たおすほど アクセル(さいだい 3.3m/秒)。向きが ずれていると アクセルは 弱い。
  ぶつかった あとは 横へ すべる(グリップで だんだん 前を 向く)。手を はなすと だんだん 止まる。
- ダッシュ: ボタンを おすと 0.22 秒 ためて(ブルン)、前へ +6m/秒。ダッシュ中(0.45 秒)は 重さ 1.9 倍で、
  当てた 相手を 大きく はじく。つかったあと 1.9 秒は つかえない。ためている あいだは ゆっくり。
- ぶつかる: 重さで はねかえる(ゴムの バンパー)。強く 当てられると 少し ふらふら(0.4 秒 ハンドルが きかない)。
- リンクが ちぢむ: はじまって 16 秒から 46 秒にかけて、半径 6.5m → 3.4m へ 少しずつ。2.5 秒前に 合図。
- 回る まん中: 半径 1.9m の 円盤が 回っている(1 秒に 1.25 ラジアン)。のると いっしょに 回されて、外へ 流される。
  9〜13 秒ごとに 回る 向きが かわる。
- 75 秒たっても 決まらなければ、まん中に 近い順。
- 順位: のこった子、そのあとは 落ちたのが おそい順(同時なら、外へ 速く とんでいた子が下)。
  落ちる 2 秒前までに ぶつかった子が いたら「おしだし」として 数える。

## CPU(`src/games/bumper/cpu.js`)

- ふちに 近づきすぎたら まん中へ(外へ 走っている ときは 早めに)。回る 円盤に のったら 外へ ぬける(つよきは 気にしない)。
- ダッシュで 来る 車が 近いと、よこへ ハンドルを きって よける。
- ねらう子: ふちに 近い子・近くに いる子・ふらふらの子。その子の 内がわへ まわりこんで、
  車の 向きが 相手に そろい、近ければ ダッシュ。はじめの 数秒と、ダッシュの あとは ようすを 見る。
- 性格: しんちょう(ふちから 遠く・よく よける)/ ふつう / つよき(よく せめる・遠くから ダッシュ)。

## 画面(`src/games/bumper/game.js`, `stage.js`)

- 会場: たそがれの 遊園地の 広場。少し 高い 丸い リンク(ピンクと むらさきの チェック柄)。
  奥半分に しまの 柱と 輪の 形の 屋根(ふちに ひらひらと 電球。光が 順に 流れる)、奥に「バンパーカー」の 看板。
  まん中の 円盤は うずまきの 矢印が 回る。遠くの 空に 観覧車の かげ。観客は 奥の 広場。
- いまの ふちは 光る 輪(ちぢんでいる あいだは ちかちか)。ふちが 入ってきた 床の 輪は 暗くなり、こえると 沈む。
- 車: 子の 色の ボディに 黒い ゴムの バンパー、ハンドル、うしろの ポール(先が 光る。ダッシュで ピンク)。
  ハンドルで かたむき、ためると ぶるぶる、ダッシュで 前のめり。ぶつかると ぶるっ、星が ぱっ「ボヨン」「ドン!」。
- 落ちる: ふちから とびだして 広場へ ころん(少し スロー)。観客が よろこぶ。
- HUD: 上に みんなの 札(落ちた子は 灰色)と のこり時間、右下に「ダッシュ」(つかったあとは 輪が たまっていく)。
- のこり 2台で「いっきうち!」と カメラが 寄る。決着は 勝った子へ 寄って 紙ふぶき。
