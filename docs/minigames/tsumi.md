# どんぐりつみ

森の大きな切り株の上に、みんなでひとつの山を積む。順番に、上で左右にゆれている「森のもの」をタップで落とす。
山をくずした子・山に乗せそこねた子は脱落。最後まで残った子の勝ち(1分半〜2分)。

## 場面: 森の大きな切り株のうえ

- 森の奥の広場に、年輪の見える巨大な切り株(上の面の半径 1.6m、高さ 1.4m)。根が地面へはい、こけがつく。
- 上に大きな木の枝が張り出していて、そこから**つる**が下がる。つるの先で、次に積むものが左右にゆれる。
- 5人は切り株の**左右**に、番の順でかわりばんこに立つ(手前はあけて、山が見えるように)。番の子は少し前へ出る。
- 観客(リス・ハリネズミ・コマドリ)は、うしろ半分の小さな切り株に。高く積めるとよろこび、くずれるとおどろく。
- まわりにちょうちん。時間帯(朝・昼・夕方)は遊ぶたびに変わる。
- カメラは手前から。山が高くなると、いっしょに上がる。くずれたときはゆれる。

## 積むものの見た目

- 形は `src/games/tsumi/pieces.js`。できた形を **ルールのはば・高さにぴったり合わせる**(見た目と判定がずれないように)。
  - どんぐり: とがった先を下に立つ。上はうろこ模様のぼうしと軸。
  - クルミ: しわしわ。まん中に つなぎめ のすじ。
  - まつぼっくり: うろこを らせんに重ねる。てっぺんは小さく平ら。
  - キノコ: 赤いかさに白い水玉、裏はひだ、軸にスカート。
  - 葉っぱ: 緑・黄・だいだい・赤の4色。主脈と側脈、ふちが少し反る。
  - 小枝: 少し曲がった枝。切り口に年輪、わき枝と新芽。
- **ぽよん**: 乗ったものが ばねのようにつぶれて のびる(すぐ下のものも少し)。
- **ぐらぐら**: よゆうが少ない(0.14 より小さい)と、いちばんきわどい段のふち(重心が寄っているがわ)を支点に、
  そこから上がゆれる。よゆうが少ないほど大きく、次に積むまで止まらない。
- **くずれる**: 落ちる段から上が、支点のまわりに 0.5 秒かけてかたむいてから、ばらばらに飛ぶ(切り株の上ではねて、ふちへ転がる)。

## くずれる・脱落の演出

- くずれた・乗せそこねたときは、カメラが地面まで引いて、落ちていくがわへ少し寄る(2 秒ほど)。画面もゆれる。
- 落ちたものが はねたところに、けむりが ぽふっ。
- くずした子: 目を回して(dizzy)→ うつむいて両手をだらん → こちらへ向きなおり、うしろへ下がる。
  頭の上に小さな雨雲(5 秒ほど)。
- 「○○ だつらく」の札が上からおりてくる(色の丸に ×、のこりの人数)。番の札は うすく、名前に線。

## 動かし方

- 自分の番のとき、画面のどこかを**タップ**(パソコンはスペース / Enter)すると、ゆれているものが落ちる。
- 7 秒たっても落とさないと、ひとりでに落ちる(のこり時間のバーが下に出る)。

## ルール

- 番の順はくじ。脱落した子はとばす。
- 積むもの(くじで出る。右上に「つぎ」が見える):

  | もの | はば | 高さ | 上の面の乗せやすさ |
  | --- | --- | --- | --- |
  | どんぐり | 0.5 | 0.55 | 0.88(丸い) |
  | クルミ | 0.56 | 0.5 | 0.92 |
  | まつぼっくり | 0.56 | 0.92 | 0.82(とがっている) |
  | キノコ | 0.92 | 0.5 | 1.0 |
  | 葉っぱ | 1.15 | 0.12 | 1.0(平ら) |
  | 小枝 | 1.4 | 0.16 | 1.0 |

- 山は横から見た1列の積み重ねで考える。どの段でも「その上にあるもの全部の重心」が、
  その段の上の面(はば/2 × 乗せやすさ + 0.03)からはみ出したら、そこから上がくずれる。
  ざっくり「乗せたものの まん中が、下のものの上にあれば乗る」(見た目どおり)。
  - はじめは丸いものをもっとすべりやすく(0.6 くらい)していたが、見た目では乗るのに落ちることが多く、
    きびしすぎたので ゆるめた(どんぐりの上のどんぐり: 重なって見える はばの 30% → 49% で乗る)。
  下の段がずれていても、上で反対へもどせば立つ。
- 山のてっぺんにかすりもしなければ、乗せそこね(脱落。山はそのまま)。
- くずした子は脱落。山は切り株からやりなおし。
- ゆれは、山が高くなるほど・投げた回数が多いほど、速く大きくなる(いつかはだれかがくずす)。
- 投げた回数が 160 になったら、残っている子でおしまい(多く積んだ子が上)。
- 順位: 残った子 → あとまで残った順。

## CPU

- 番が来たら少し見てから(しんちょう 0.6〜0.9 秒 / ふつう 0.45〜0.75 / つよき 0.3〜0.55)、
  山がいちばん安定するところをさがす(しんちょうほど細かく)。
- ゆれがそこを通るときを読んでタップする。タイミングは人と同じくらいずれる(0.06〜0.08 秒)。
- テスト(`test/tsumi.test.js`)で、人くらいの反応(0.6〜1.0 秒・ずれ 0.08 秒)でも平均 3.4 位以内・1割以上勝てることを見張っている。

## 大会

- 大会の競技にも入る。2人の対決にも使う(2人でも決着する)。
