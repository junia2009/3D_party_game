# 花ぬり陣取り

丘の上の まん丸な花畑を、5人が走りまわる。通ったところに自分の色の花が咲く。
45 秒で、いちばん広く咲かせた子の勝ち。

## ルール(`src/games/hana/rules.js`)

- 花畑は半径 6m の まん丸(40cm のます目)。まん中に大きなひまわり(通れない。花も咲かない)。
- 走ると、足もとの半径 0.5m が自分の色になる。ほかの子の花も、上を走れば咲きかえられる。
- はじめは、それぞれの足もとに少しだけ咲いている。3 秒の「よーい」のあと 45 秒。のこり 10 秒で「ラストスパート」。
- じょうろ・ミツバチ: 4.5〜6.5 秒ごとに(同時に 2 つまで)、人から少しはなれたところに出る。9 秒で消える。
  - じょうろ: 拾うと、まわり半径 1.7m を一気に自分の色に。
  - ミツバチ: 拾うと 5 秒のあいだ、通り道が太くなる(半径 0.95m)。
- つむじ風: はじまって 9 秒、そのあと 8〜11 秒ごと。花畑の外から外へ、まん中のあたりを横切る。
  出てくる 1.2 秒前に、来る道を知らせる。通ったところ(半径 0.85m)の花は散って、だれのものでもなくなる。
  当たった子は横へ飛ばされて、0.8 秒 目が回る(そのあいだは咲かない)。
- 体当たり: ほぼ全速力(3.5m/秒より速く)で まっすぐ当てると、当てられた子が 0.9 秒ふらふらして、
  そのまわり半径 0.95m が当てた子の色に。向かいあって ぶつかったとき(出あいがしら)は、どちらも当てていない。
- 順位は咲かせた広さ(ます目の数)。同じなら席の順。

## CPU(`src/games/hana/cpu.js`)

- 人と同じく「どこへ向かうか」だけを出す。0.3〜0.55 秒ごとに考えなおす。
- まわりの行き先をいくつかくらべて、とちゅうで まだ咲いていない・ほかの子の色の ます目を いちばん多く通れるところへ。
- じょうろ・ミツバチが近くにあれば取りに行く(先に だれかが着きそうなら あきらめる)。つむじ風の通り道は さける。
- 性格: しんちょう(風をよくさける)/ ふつう / つよき(じょうろが大すき・風をあまり気にしない・ときどき体当たりしに行く)。

## 画面(`src/games/hana/game.js`, `stage.js`)

- 会場: 森をぬけた丘のてっぺん。まん丸な花畑(やわらかい土と、ふちの石)、木の柵(入り口が4つ)、
  うしろに大きな風車(羽根が回る)、柵の外の切り株に観客。丘はゆるく下って、ふもとは森。遠くに山なみ。
  柵の外には野の花。正面の入り口から ふもとへ土の道が下り、入り口に「花ぬり陣取り」の看板。
- 花: ます目ごとに1りん(花びら + 濃い色のまん中 + くきと葉)。形もプレイヤーごとにちがう
  (あか: まるい5まい / あお: ほそい花びら / きいろ: とがった6まい / みどり: 大きな4まい / むらさき: 2だん)。
  札と結果にも同じ形の花を出す。まだ咲いていない土には、小さな芽。持ち主が変わると ぽんと大きめに咲いて、ゆれて落ちつく。
  咲きかわるときは前の色の花びらが少し舞う。つむじ風で散るときは、しぼんで花びらが舞い上がる。
- じょうろ: 水色のブリキのじょうろが ふわふわ回る(水色の輪)。拾うと じょうろが ふわっと浮かんで、
  回りながら まわりへ水をまく。小さな にじがかかり、まん中から外へ波のように咲く。
- ミツバチ: 顔のある しましまのハチが ぶんぶん(金の輪)。拾うと その子のまわりを飛びまわって、花粉のきらきらを落とす。
  時間ぎれで上へ飛んでいく。
- つむじ風: 知らせのあいだは、来る道に赤い矢じるしが流れ、来るところに「!」がはねる。
  そのあと ねじれて巻き上がる ろうと形のうず(足もとに土ぼこり、まきこまれた葉っぱ)が道を進む。近くを通ると画面が少しゆれる。
- 体当たり: 当てた子の色の花びらが ぱっと散る。「ドーン!」(当てられたら「とられた!」)。
- ひまわりは、いま いちばん広い子のほうへ、ゆっくり顔を向ける。
- HUD: 上に それぞれの広さ(%)の札(広い順にならぶ。いちばんの子は金のふち)、時計、一時停止。
  ラストスパートは画面のふちが花の色に脈打ち、1 秒ごとに秒読み(のこり 3 秒は大きな数字)。
  トップが入れかわると、左上に小さな札(「トップ!」「トップを とられた!」「○○が トップ!」)。
- 決着: カメラが上がって花畑ぜんぶを見せる。「ひろさくらべ」の帯が広い順にのびて、勝った子の名前。
  勝った子の花が、その子のところから波のように はねて、紙ふぶき。
- 操作: どこでもスティック(キャッチと同じ)。パソコンは矢印キー / WASD。
