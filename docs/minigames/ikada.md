# いかだレース

朝もやの森の川を、5人がそれぞれのいかだで下る。画面の左と右を こうごに たたいて こぐ連打の競技。
先にゴール(ビーバーのダムの水門)へ着いた子の勝ち(45〜60 秒)。

## 場面: 朝もやの森の川

- 静かな池(スタートの桟橋と門)→ 岩のある左カーブ → 急流 → 小さな滝 → うずと流木のゆるやかな所 →
  木の根のトンネル → 2つめの急流と滝 → 広い所(うず・流木)→ ビーバーのダムの水門(ゴール)。
  ゴールのあとはダムの前の池で、流れが止まる。
- 水面は流れる模様。急流と滝のまわりは白くあわだつ。岸はこけと しだ、まわりは緑の森(広葉樹と針葉樹)。
- 木の根のトンネル: 大きな根が川の上にアーチになる(こけ・たれさがるつる)。中ではカメラを低く。
- ゴール: 水門の門(旗)・ホーホー先生・岸の切り株に観客。うしろに丸太を積んだダム。
- 時間は朝(霧を近くして、朝もやに)。
- 空気と飾り(`src/games/ikada/scenery.js`):
  - 朝もや: 川の上を ゆっくりただよう霧。前が見えにくくならないように岸ぞいに多く、カメラに近いものは うすく。
  - 木漏れ日: 岸の木の下から川へ、ななめに差しこむ光の筋(上は木の葉の下で止める)。トンネルの中にはない。
  - 川面のきらめき: 水面で ちかっと光る星の形の点(速い流れほど よく光る)。
  - 岸の草花: 水ぎわにガマの群れ、岸の上に白・黄・桃・うす紫の小さな花としだ。
  - 滝: 落ち口から放物線で落ちる水のカーテン(白いすじが下へ流れる)、下で広がりつづける あわの輪、しぶきの霧。
    落ち口の両わきに こけの岩。
- 木の根のトンネル: でこぼこで根もとほど太い根のアーチ(上の面に こけ)。両はしは岸の土へもぐる。
  わき根・たれさがる つる(先に葉)・根もとに ほんのり光る小さなキノコ。

## いかだと こぐ動き

- いかだ(`src/games/ikada/raft.js`): 木の皮の丸太5本(長さを少しずつ変える)、切り口に年輪。
  前とうしろを なわで ぐるぐるしばる。まん中に葉っぱのざぶとん、前に どんぐりの袋、うしろに自分の色の三角の旗(ゆれる)。
- かい: 両はしに水かきのある カヤックのかい(こうごに こぐのに ぴったり)。水かきのつけねに自分の色の帯。
- ひとかき: はしを前で水に入れて → うしろへかいて → 上げる。体も こぐがわへ ひねって 前後にゆれる。
  ひとかきの長さは、前のかきからの間に合わせる(速くこぐと動きも速い)。
- 水: かいが水に入ったところに 波紋としぶき。いかだのうしろに引き波(速いほど こく、長く)。
- こぐリズム(画面の下のまん中): 左右のランプ・こうごの数・ひとかきの強さのメーター
  (緑 = ぐいっと、黄 = もう少し間を、赤 = 速すぎ/同じがわ)。
  ことばでコツを教える: 「おなじがわ! こうごに」「はやすぎ! ぐいっと」「いいリズム! 10」。

## 仕掛けの演出

- 岩・流木: ぶつかったところに大きなしぶきと波紋。いかだが ぐらっとゆれて(ばねのように もどる)、くるっと1回転。
  回っているあいだは目を回す(dizzy)。「ガツン!」(流木は「ゴツン!」)が その場に出る。画面もゆれる。
- うず: 白いあわのつぶが らせんに まわりながら まん中へ吸いこまれる。だれかが入っていると はげしく回る。
  入った子は まん中へかたむき、しばらくすると目を回す。自分のときは「うずだ!」「れんだで ぬけだせ!」→ 抜けたら「ぬけた!」。
- 滝: 落ち口に近づくと、カメラが高く上がって 下の滝つぼを見下ろす。落ちるあいだは上に残って見送り、落ちたら追いつく。
  落ちたら「ざぶーん!」・大きなしぶき・画面に水しぶき。
- 体当たり: 当たったところに「ドン!」・しぶき・波紋。当てられたほうが大きく ぐらっとゆれる。2人ともおどろいた顔。

## ゴールと盛り上げ

- 水門の扉: 門の柱から まん中まで、板の扉が左右に1枚ずつ。いちばん前の子が 20m まで来ると、下流へ ぎいっと開く。
- ビーバー: ダムの上で2ひきが応援。だれかがゴールすると とびはねて、しっぽで水をたたく(しぶき)。
- 紙ふぶき: 1位がゴールしたときと、自分がゴールしたときに、門の上から ふきだす。
- 順位の入れかわり: 「○○を ぬいた! 2位」「○○に ぬかれた… 3位」(順位の下に小さな札)。
  ならんで押しあうと行ったり来たりするので、0.4 秒そのままだったときだけ知らせる。
- ラストスパート: のこり 45m で「ラストスパート!」と太鼓、観客がよろこぶ。
- 自分がゴールしたあと: カメラが いかだのうしろから前へ ゆっくりまわりこんで、よろこぶ顔を見る。
- ずっと: 川の音(急流で大きく)と、ときどき森の鳥。
- 「おなじがわ! こうごに」は、同じがわが 4回つづいたときだけ(曲がるときに わざと使うので)。

## 動かし方

- 画面の左半分・右半分を **こうごに** たたく(パソコンは ← → / A D。押しっぱなしは数えない)。
- 本物の舟と同じく、右がわをこぐと左へ、左がわをこぐと右へ向く(こいだがわが前へ押される)。
  同じがわを続けると大きく曲がる(そのかわり進みは弱い)。
  - はじめは「たたいたがわへ曲がる」にしていたが、かいの動きと合わず不自然だったので、本物と同じにした。
- カメラは自分のいかだを うしろから追う。

## ルール

- 川にそった座標(s: 道のり、x: 横)。いかだは「こいだ速さ v」と「向き yaw」を持つ。
- 1かき: こうごなら v += 0.8、同じがわなら 0.55 倍。向きも変わる(同じがわは大きく)。かいで横へも少し押す。
  - かいが水をとらえるには間がいる: 前のかきから間がないほど弱い(1 - e^(-間/0.12))。連打の速さだけで決まりすぎないように。
  - 1秒に 13 回より速いタップは数えない。
- 水の抵抗(速さと速さの2乗に比例)で頭打ち。流れ(ふつう 2.2m/秒、急流 4.6〜4.8m/秒)がいつも運ぶ。
- 岸: こすると遅くなって、まん中へ向きなおる。
- 岩・流木: ぶつかると、こいだ速さが 1/4 になって少しはねかえり、くるっと1回転(0.8 秒。そのあいだは こいでも半分)。
  当たりはじめだけ数える。岸に近い岩は、川のまん中のほうへよける(すきまに はまらない)。流木はゆっくり左右に流れている。
- うず: 近づくと吸いこまれて、まわりを回される。まん中では流れに運ばれない。強くこいで抜け出す。
- 小さな滝: 0.6 秒 宙に浮いて、落ちたあと勢いがつく(+1.4)。自分のときは画面に水しぶき。
- いかだどうし: 押しあう。当てにいったほうより、当てられたほうが大きくはじかれる。
- 1人めがゴールしてから 12 秒でおしまい。順位はゴールした順、まだの子は進んだ道のりの順。

## CPU

- こぐ速さ(1秒に しんちょう 5.0 / ふつう 5.4 / つよき 5.8 回)、ときどき息つぎ。
- 前に見える岩・流木(着くころの位置)・うず・ほかのいかだ を見て、通る横の位置を点数でえらぶ。
  当たるところは ふちから少し余裕をもって、近いものを またいで動く道は さける。カーブは内がわ。
- ねらいの向きより右を向きすぎていたら左を、左なら右をたたく。ちょうどよければ交互。
- テスト(`test/ikada.test.js`)で、人くらい(1秒に6回・反応 0.4〜0.6 秒)でも平均 3.4 位以内・1割以上勝てることを見張っている。

## 大会

- 大会の競技に入る(5人の競技。そりと同じく、2人の対決には使わない)。
