# 大会(すごろく)

5人で「四季の森」の盤をまわり、**金どんぐりメダル**を集める。競技(ミニゲーム)はターンの合間に入る。
いちばんメダルの多い子が優勝(同じなら、どんぐりの多い子)。

> この文書は **案**。数字は遊んでみて直す。決まったことは「決まり」に、迷っていることは「あとで決める」に書く。

## 決まり(ユーザーと決めたこと)

| こと | 決まり |
| --- | --- |
| 盤の舞台 | **四季の森**。ぐるっと一周する盤が、春・夏・秋・冬の4つのエリアに分かれている。エリアごとにしかけがちがう |
| 勝ち方 | **メダルを買って集める**(マリオパーティのスター型)。ホーホー先生にどんぐりを払うとメダル。先生は別の場所へ移る |
| 長さ | **えらべる**: 5 / 10 / 15 ターン |
| サイコロ | **1〜10 のどんぐりサイコロ**。空中でくるくる回る数字を、タップで止める |
| マス | **どんぐりのプラス・マイナス**・**どうぐ**・**ハプニング**・**対決** |
| 最後 | 表彰台の前に**ボーナスメダル3つ**(その回によって変わる) |
| CPU の番 | ふつうに見せて、**「はやく」ボタン**で早送り |
| ステージ | **ステージ選択画面**をつくる。いまは「四季の森」だけ。ほかは「じゅんびちゅう」(あとで足す) |

## 1回の流れ

1. **ステージ選択**: 競技えらびと同じ形のカード。いまは四季の森だけ、ほかは「じゅんびちゅう」。
2. **入口**: ターン数(5/10/15)とキャラをえらぶ。空いた席は CPU。
3. **開会式**: 盤の上空からぐるっと見せる。みんなでサイコロをふって、大きい順に番の順を決める。
   はじめに どんぐり 10 こずつ。先生(メダル)の最初の場所をくじで決める。
4. **ターン**(これを決めた回数):
   1. 番の順に、1人ずつ: (どうぐを使う)→ サイコロ → 進む(とちゅうで先生・お店・分かれ道)→ 止まったマスの効果。
   2. 全員が動いたら **競技**。4つの競技からくじ(同じものが続かないように)。順位でどんぐり。
5. **ラストスパート**(のこり3ターン): 先生が「さいごの3ターン!」。青マス・赤マスのどんぐりが2倍。
6. **ボーナスメダル**: 候補から3つ発表。
7. **表彰台**: 1〜3位が台に。優勝の子に金どんぐりメダル。紙吹雪。

## 盤: 四季の森

輪っかになった道(全部で 48 マスくらい)。4つのエリアに 12 マスずつ。とちゅうに分かれ道が2〜3か所。
スタート(開会式の広場)は春と冬のさかいめ。

| エリア | 景色 | エリアだけのしかけ |
| --- | --- | --- |
| 春 | 池とハスの葉、桜 | **ハスの近道**: 分かれ道。ハスの葉をぴょんぴょん渡る近道は短いが、ハプニングマスが多い |
| 夏 | 深い緑の森、大きなどんぐりの木 | **どうぐ屋**(大木の根もとのお店)。通りすぎるときに寄れる |
| 秋 | 紅葉の山道(そりレースの山) | **落ち葉すべり台**: 止まると、すべって先のマスまで一気に進む |
| 冬 | 雪原と凍った池 | **つるつる氷**: 氷の上のマスで止まると、もう1〜3マスすべる(どこで止まるかわからない) |

## 盤: どんぐり遊園地(`stages/yuen.js`・`scene-yuen.js`)

四季の森より 小さめ(36 マス・分かれ道なし)で、ぶつかりやすい。4つのエリアに 9 マスずつ。
島は 角の まるい 四角(`isleShape: 4`)で、道の外の 奥に 高い 乗り物(コースター・観覧車)を 置く。
スタートは 入口の ゲートの 前(開会式・表彰台は ゲートを うしろに)。

| エリア | 景色 | 乗り物(乗り場マス) |
| --- | --- | --- |
| 入口広場 | ゲート・風船屋さん・どうぐ屋 | ― |
| コースター | 宙がえりの ある ジェットコースター | **ジェットコースター**: 大当たり 20% / 8〜12 マス先 50% / 3〜5 マス もどる 30% |
| 観覧車 | 観覧車・メリーゴーラウンド・コーヒーカップ | **観覧車**: 大当たり 25% / 盤の どこかへ 45% / その場で どんぐり +6 30% |
| おばけ屋敷 | おばけ屋敷・かぼちゃ・ふわふわ おばけ | **おばけ屋敷**: 大当たり 15% / 5〜9 マス先 45% / 6〜9 マス もどる 40% |

- **乗り場**に ちょうど 止まると、どんぐり 3 こで 乗るかを えらべる(たりなければ 乗れない)。
  行き先は くじ。**大当たり**は ホーホー先生の 1 マス手前。着いた マスの 効果も 受ける(乗り場なら もう 乗らない)。
- CPU: 先生が 8 マス以内で メダルが 買えるなら 乗らない。それ以外は 性格しだい(つよきは よく 乗る)。
- 演出: コースターは レールを 1周(カメラが 追う)、観覧車は ゴンドラで てっぺんまで、
  おばけ屋敷は 中へ 消えて 家が ゆれ、えんとつから とびだす。そのあと 行き先へ 大きく とぶ。

## マス

| マス | 色 | 効果 |
| --- | --- | --- |
| 青 | 青 | どんぐり +3 |
| 赤 | 赤 | どんぐり -3 |
| どうぐ | 緑 | どうぐを1つもらう(くじ) |
| ハプニング | 紫 | エリアごとのできごと(下) |
| 対決 | だいだい | 1人をえらんで、どんぐりをかけて 1対1 の競技 |
| 先生(メダル) | 金 | 先生のいるマス。**通りすぎるときにも**寄れる。どんぐり 20 こでメダル 1 つ |

- どんぐりは 0 より下にならない。
- 先生からメダルを買うと、先生は別のマス(くじ。いまの場所から遠いところ)へ飛んでいく。

### どうぐ(3つまで持てる)

| どうぐ | 効果 | お店の値段 |
| --- | --- | --- |
| ふたつサイコロ | サイコロを2つふる(2〜20) | 5 |
| みっつサイコロ | サイコロを3つふる(3〜30) | 10 |
| いれかえの葉っぱ | だれか1人と場所を入れかえる | 10 |
| 先生の笛 | 先生を、自分の前(1〜10 マス先のどこか)へ呼ぶ | 20 |
| どんぐり袋 | どんぐり +10 | (お店にはない。どうぐマスだけ) |

### ハプニング(エリアごと)

| エリア | できごと |
| --- | --- |
| 春 | **春の雨**: 池があふれて、止まった子が 3 マスもどる |
| 夏 | **どんぐりの雨**: 夏の大木がゆれて、止まった子はどんぐり +10、まわり(前後3マス)の子は +3 |
| 秋 | **つむじ風**: 止まった子が、盤のどこかへ飛ばされる(くじ) |
| 冬 | **雪玉ころころ**: 大きな雪玉が転がって、冬にいる子はみんな どんぐり -5 |

遊園地:

| エリア | できごと |
| --- | --- |
| 入口広場 | **風船**: 風船に つかまって、止まった子が 3〜5 マス 先へ |
| コースター | **宙がえり**: 止まった子が どんぐりを 5 こ 落とす。コースターに いる ほかの子が 山分け(わりきれない ぶんは なくなる) |
| 観覧車 | **花火**: みんな どんぐり +3、止まった子は +6 |
| おばけ屋敷 | **おばけの いたずら**: 止まった子と、くじで えらばれた ほかの子の 場所が 入れかわる |

止まると、盤の上で 5 秒くらいの 3D 演出が 入る(カメラが よって、画面の ふちが 季節の 色に そまる)。
春は 雨雲と 雷 → 波に 押しながされる、夏は どんぐりの 雨 → 金の どんぐりが 頭に ゴツン、
秋は 落ち葉の 竜巻に 巻きあげられて 弧を えがいて とんでいく、冬は 大きくなりながら 転がる 雪玉に みんな ぺしゃんこ。

### 対決

- 止まった子が相手を1人えらぶ。かけるどんぐりは 10(持っている数が少ないほうに合わせる)。
- 競技を **2人用・短い時間**(30 秒くらい)で。勝ったほうが、かけたどんぐりをもらう。
- 2人用にしやすい競技から: まつぼっくり的あて・どんぐりキャッチ・だるまさん・どんぐりつみ(そりは5人のほうが楽しいので外す)。

### 競技のごほうび

| 順位 | 1位 | 2位 | 3位 | 4位 | 5位 |
| --- | --- | --- | --- | --- | --- |
| どんぐり | +10 | +6 | +4 | +2 | +1 |

競技の中で拾ったもの(だるまさんのどんぐりなど)は、ボーナスにする(1こ +1)。

### ボーナスメダル(候補から3つ)

| ボーナス | だれに |
| --- | --- |
| 競技の王さま | 競技で1位をいちばん多く取った子 |
| ひろい屋さん | どんぐりをいちばん多く拾った子(ぜんぶの合計) |
| ハプニング王 | ハプニングマスにいちばん多く止まった子 |
| 大また | サイコロの目の合計がいちばん大きい子 |
| 対決の名人 | 対決でいちばん多く勝った子 |
| 買いもの上手 | どうぐをいちばん多く使った子 |

同じ数ならみんなにあげる。

## CPU

人と同じことしかしない(サイコロを止める・分かれ道・どうぐ・メダルを買う・対決の相手)。
- サイコロ: 止めるタイミングに少しくせがあるだけで、目は人と同じく運(目を選べない)。
- 分かれ道: 先生に近いほう。性格で、近道(ハプニング多め)の好みがちがう。
- どうぐ: 先生が近いときにふたつサイコロ、先生が遠くて自分がビリのときに先生の笛、など。
- 対決: どんぐりをいちばん多く持っている子をえらぶ(つよき)/ えらばない(しんちょう)。

## 画面

- 盤は斜め上から。手番の子をカメラが追う。サイコロは手番の子の頭の上。
- 上に5人の札(顔・メダル・どんぐり)。下に「サイコロをふる」「どうぐ」。
- CPU の番は右下に「はやく ▶▶」。押しているあいだ3倍速。

## 作り(ルールと画面を分ける)

- `src/board/rules.js`(THREE にも DOM にも触らない): ターン・マス・どうぐ・ハプニング・対決・メダル・ボーナス。
  盤の形は知らない。ステージのデータを受け取って動く。state を書きかえるのは act(手番の子の操作)だけ。サーバーでも回せる。
- `src/board/stages/<名前>.js`(THREE にも DOM にも触らない): ステージのデータ。マスのつながり・種類・エリア・
  エリアのしかけ・先生が立てるマス・画面用の位置。**ステージを足すときは、ここにファイルを1つ足す**。
  ステージの一覧は `src/board/stages/index.js`(じゅんびちゅうの札もここ)。
- `src/board/cpu.js`、`test/board.test.js`(CPU だけで大会を最後まで回す・どんぐりの出入りが合う・決着する)。
- 競技は「参加者を受け取って、順位を返す」口を足す(いまは結果画面まで自分で出している)。
  大会から呼ぶときは結果画面を出さずに、順位を返して盤へもどる。

## 作る順番(案)

1. ルール・CPU・テスト(画面なしで大会を最後まで回せる)
2. 競技を大会から呼べるようにする(順位を返す口)
3. ステージ選択画面と、盤のラフ(四季のエリア・マス・コマ・サイコロ)で、遊べるところまで
4. 作り込み(盤の景色・サイコロの演出・ハプニングの演出・表彰台…)は、ラフを見てから順番を相談

## 画面のつながり

- メニューの「すごろく」→ ステージ選択(`#stages`。地図の本。島をタップ)→ 入口(`#play` に、ターン数のえらびを出す)→ 盤。
  `#taikai` で入口から直接ひらける。
- 盤(`src/board/game.js`)は、タイトルから見ると競技と同じ「会場」の1つ。競技へ行くときは、タイトルの
  `playMinigame(競技, 顔ぶれ, 自分のキャラ)` が葉っぱの幕で会場を入れかえ、順位をもらって盤へもどす。
- 競技のとちゅうで「メニューへもどる」と、大会もおわる。

## 演出と音

- **盤**(`src/board/scene.js`): 季節の地面の色を混ぜて境目をなめらかに。季節の看板・小物(チューリップ・ひまわり・キノコ・雪だるま)。
  季節ごとに舞うもの(桜の花びら・チョウ・落ち葉・雪)。マスの札は止まるとぽんと弾む。
- **進み方**(`src/board/game.js`): できごとを1つずつ、ゆっくり見せる。カメラは手番の子を中心に、ゆっくりついていく。
  止まったマス・ハプニング・どうぐ・先生・対決・競技は、画面下の説明カードで「何が起きるか」を言う。
- **サイコロ**: 頭の上で回るどんぐり。止めるとコマが跳んで頭突き、殻が割れて目が出る。進むあいだは、のこりのマス。
- **演出**(`src/board/effects.js`): 先生の光の柱・弧をえがいて飛ぶ先生・メダル・どうぐの形・春の雨・どんぐりの雨・
  つむじ風・雪玉・表彰台・紙吹雪。
- **表彰式**: スタートの広場の奥に台がせり上がり、3位・2位・1位の順に跳び乗る(1位の前にドラムロール)。
  先生から1位へ金どんぐりメダル、紙吹雪、歓声。
- **音**: 一歩(季節で音色がちがう)・サイコロ・番のはじめ・羽ばたきとホーホー・どうぐ・すべり台・ハプニング(雨・どんぐり・風・雪玉)・
  対決・ドラムロール・ファンファーレ。まわりの音は手番の子のいる季節で変わる(春の小鳥・夏のセミ・秋の風・冬の静かな風)。

## あとで決める

- 盤の景色の方向(ラフの前にスケッチを見せて相談する)
- 対決の競技の時間と、2人用の調整
- オンライン(手番の待ち時間・切断したとき)

## つづきから(`src/board/save.js`)

- 大会の とちゅうは、手番が すむたびに 端末に 保存する(大会の 状態・CPU の 乱数・顔ぶれ・自分の キャラ)。
  ページが 読み込みなおされても(スマホの メモリ不足・うっかり 閉じた など)、さいごの 手番から つづけられる。
- 競技の とちゅうで 切れたときは、その 競技を はじめから やりなおす。
- メニューの「すごろく」に「つづき」の しるし。ステージの 地図の 上に「つづきから」(ステージ・ターン・メダル・どんぐり)と
  「この大会を けす」(2回 おすと けす)。新しい 大会を はじめると 上書き、大会が おわると けす。
